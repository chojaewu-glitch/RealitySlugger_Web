RealitySlugger_Web
카메라를 이용한 야구 타격 웹 게임
REALITY SLUGGER

카메라를 이용해 실제로 스윙하면서 즐기는 웹 야구 게임입니다.

프로그램 소개
REALITY SLUGGER는 기존 C++ 콘솔 야구 게임을 HTML, CSS, JavaScript를 이용해 웹브라우저에서 실행할 수 있도록 발전시킨 프로그램입니다.
카메라에서 빨간색 표식의 움직임을 인식하고 스윙 타이밍에 따라 홈런, 안타, 파울, 헛스윙을 판정합니다.

주요 기능
카메라를 이용한 빨간색 물체 추적 및 스윙 인식
쉬움, 보통, 어려움 난이도 선택
직구, 슬라이더, 체인지업 선택
10구 자동 투구 진행
홈런, 안타, 파울, 헛스윙 판정
점수, 홈런 수, 안타 수, 최고 비거리 표시
PC 및 스마트폰 화면 지원

사용 방법
웹사이트에 접속합니다.
난이도와 구종을 선택합니다.
카메라 연결 버튼을 눌러 권한을 허용합니다.
빨간색 표식을 카메라에 보여줍니다.
투구 시작 버튼을 누릅니다.
공이 가까워질 때 빨간색 표식을 좌우로 빠르게 움직입니다.
총 10번의 투구가 끝나면 최종 기록을 확인합니다.
카메라가 없는 경우 스윙 테스트 버튼이나 스페이스바로 타격을 테스트할 수 있습니다.

개발 기술
HTML: 게임 화면 구성
CSS: 야구장 디자인 및 반응형 화면 구현
JavaScript: 투구, 타격 판정, 점수 계산
WebRTC getUserMedia: 카메라 연결
Canvas API: 빨간색 표식 추적
GitHub Pages: 웹사이트 배포
